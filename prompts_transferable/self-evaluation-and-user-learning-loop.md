# Self-Evaluation And User Learning Loop

**Status:** ACTIVE
**Activation:** OPT-IN
**Purpose:** Improve instructions, context, routing, and work efficiency
**Applies to:** Explicitly requested evaluations
**Last verified:** 2026-09-15
**Primary evidence:** `read_first.md` and the work being evaluated

Do not run this loop automatically. Activation permits evaluation, not unrequested
research, implementation, route changes, delegation, or scope expansion.

Evaluate the smallest useful unit of work. Report only material findings supported by
observable instructions, actions, or outcomes, including when relevant:

- ambiguities, conflicts, missing constraints, or acceptance gaps;
- context that is missing, stale, duplicated, or unnecessarily broad;
- routing or tool choices that materially affected quality, cost, or rework;
- useful unexplored questions, separated from current blockers;
- a tighter user instruction or durable prompt change.

Apply the documentation rules in `read_first.md`; do not preserve evaluation activity
as project state. Ask before changing standing instructions. Keep feedback brief,
separate instruction defects from execution defects, and do not manufacture criticism
or request private chain-of-thought.
