# Grill Me

This is the explicit router for the interview workflow.

## Workflow

Load and follow `matt-grilling` for the plan, design, decision, or idea being tested.
Look up available facts rather than asking the user to retrieve them. Do not implement
or document the result unless separately requested; use `matt-grill-with-docs` when
the user wants durable domain documentation during the interview.

## Authority

Project and user policy overrides this skill. Invocation does not authorize
dependency installation, Git or remote operations, scope expansion,
destructive actions, or unrelated writes.
